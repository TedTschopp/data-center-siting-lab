# NERC Reserve-Margin Derived Artifacts

These artifacts are generated from the staged NERC 2025 Long-Term Reliability
Assessment PDF with:

```bash
python -m reVeal.public_data generate-nerc-reserve-margin-features \
  --regions tests/data/downscale/inputs/regions/eer_adp_zones.gpkg \
  --grid tests/data/downscale/inputs/grid_char_weighted_scores.gpkg \
  --output-dir external-data/derived/nerc
```

The workflow produces:

- `nerc_ltra_2025_assessment_area_margins.csv`
- `nerc_ltra_2025_emm_zone_margins.gpkg`
- `nerc_ltra_2025_grid_margins.gpkg`

Method summary:

- Source values come from Table 2 in the staged 2025 LTRA PDF.
- The transform computes annual reserve-margin headroom as `ARM - RML` for 2026-2030.
- The conservative feature carried through the workflow is
  `min_margin_headroom_2026_2030`.
- The EMM-zone layer uses a repo-local crosswalk from `emm_zone` names to NERC
  assessment areas.
- The optional grid artifact is generated by area-weighted transfer from the EMM-zone
  feature layer and only includes cells that overlap the mapped study area.

The assessment-area CSV keeps the full transcribed table. The zone and grid artifacts
only use the assessment areas that map into the repo's U.S. EMM-zone geometry.
