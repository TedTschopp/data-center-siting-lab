# external-data

Repo-local staging area for sourced datasets and provenance.

## Tracked

- `manifest/` holds the dataset inventory, unresolved gap register, and open substitute matrix.
- `provenance/` holds human-readable notes on where a source artifact came from, what was verified, what is missing, and how current public substitutes differ from report-equivalent inputs.
- `provenance/report-reproduction-gaps.md` collapses the remaining exact-vs-proxy reproduction blockers into a single execution view.
- `provenance/data-center-bundle-deviations.md` summarizes the current report-bundle deviations for coworker and publishing review.
- `provenance/ribits-manual-acquisition.md` records the current manual-only decision for RIBITS portal acquisition.
- `provenance/urdb-acquisition.md` records the direct staging decision for URDB.
- `provenance/public-geospatial-staging.md` now records the representative acquisition workflow for the staged public geospatial datasets.
- `derived/` holds reproducible small outputs generated from staged public-source artifacts. Subdirectories may include their own README files that explain which payloads are tracked and which are regenerated locally.
- `derived/report-bundle/README.md` is tracked as the report-bundle policy file. The generated report-bundle payloads in that directory are ignored and should be recreated from the CLI command.

## Ignored

- `raw/` is for downloaded source archives and files.
- `unpacked/` is for extracted working copies.
- `examples/` is for runnable local example bundles generated by `stage-example-bundle`.
- Generated report-bundle HTML, GeoPackage, JSON, CSV, Markdown, and cache payloads under `derived/report-bundle/` are ignored except for the tracked README policy file.

The ignored directories are intended to support local research and transformation work
without committing large binaries into git.
